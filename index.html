Como adicionar um link

  1. Abra data/links.json no editor do GitHub (funciona bem no celular).
  2. Copie um item de exemplo em items e cole outro logo abaixo.
  3. Ajuste title, url, section (favoritos / compras / desejos e category.
  4. Clique em Commit changes. Em alguns minutos o GitHub Pages atualiza o site.

Ou use o bookmarklet: arraste o link abaixo para a barra de favoritos. Em qualquer página, clique nele para abrir um issue no GitHub já preenchido com o título e a URL atuais.
